🎬 Movie Recommendation Engine Using Pure SQL

📌 Project Overview

This project focuses on building a movie recommendation engine using MySQL 8.0. It analyzes user ratings, identifies similar users, and generates personalized movie recommendations using collaborative filtering techniques.

🛠️ Tools & Technologies

MySQL 8.0
MySQL Workbench
MovieLens 100K Dataset

📊 Key Features

Database design using Primary and Foreign Keys
Movie and rating analysis
User preference analysis by genre
User similarity analysis
Collaborative filtering
Personalized movie recommendations

📂 Dataset

MovieLens 100K Dataset – 100,000 ratings, 943 users, and 1,682 movies.

🎯 Objective

To demonstrate SQL skills in data analysis, complex queries, joins, aggregations, and recommendation logic without using Python or machine learning libraries.
